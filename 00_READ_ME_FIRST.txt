## 🔄 HOW IT WORKS

```
You click button on Website
              ↓
Flask server receives request
              ↓
Server executes Python code
              ↓
Result stored in MongoDB
              ↓
Website displays result to you

Meanwhile (optional):
Client on child's PC polls MongoDB every 5 seconds
Finds pending commands
Executes them
Stores results back

Complete cycle: ~1 second ⚡
```
